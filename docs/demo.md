# 息刻 Demo 说明

## 定位与体验路径

息刻以健康素养而非疾病诊疗为目标。四类体验画像分别聚焦大学生、学生、职场人士和年长者的生活场景。匿名演示时依次切换画像，完成“首页提问或记录 -> 7/30 天回顾 -> 补记某日并观察趋势重算 -> 查看有来源的生活方式提示 -> 搜索知识 -> 助手追问 -> 重开往日提问 -> 将建议加入小行动 -> 勾选或移除”。回顾数据可按当前时段导出为 JSON。账号流程可用虚构邮箱演示：页面获取验证码、注册、首次选择年龄段和身份、选填宽泛健康分类、查看空白账号工作区、退出后再次登录或删除账号。

页面采用横向导航、较大字号和直接可见的提问入口；年长者体验提供字号放大开关，移动端使用底部导航。视觉节奏参考当代 AI 产品站点，但页面结构与内容为本项目原创。所有画像均为虚构示例；邮箱注册仅为本机演示，不验证真实邮箱所有权，不适合真实用户数据。

## 架构

```text
React 页面 -> Axios /api -> Spring REST Controller
                         -> 匿名 Cookie 工作区 -> JDBC Repository -> H2 本地文件
                         -> 账号会话 Cookie -> 独立账号工作区 -> H2 本地文件
                         -> 账号资料 -> 知识排序与首页关注点
                         -> AiService -> MockAiService / 可选 CompatibleAiService
                         -> KnowledgeCatalog (人工摘要，最多两条关键词匹配)
                         -> ReviewService (7/30 天描述性统计与资料焦点)
                         -> assistant_turn (按工作区及画像保存问答)
```

前端只处理展示、表单、知识筛选和交互状态。后端处理输入校验、最近 30 天按日期读写、按匿名工作区及画像隔离、描述性回顾、资料匹配与回答。工作区由 HttpOnly Cookie 标识，H2 本地文件在进程重启后保留记录；用户可单条删除提问，或清除当前工作区的所有记录、行动与问答。助手成功回答后保存问题和完整回答，列表显示最近 100 条，可检索及重新打开。勾选授权后才读取近七天演示记录，并只对相关话题返回描述性汇总；月度数据不会自动送往模型。有限追问可沿用上一条资料主题，但没有自然语言对话记忆；紧急和药物关键词优先分流。`AiService` 默认使用 Mock，可选兼容 Chat Completions 的实验适配器；后者只发送匹配的人工摘要和问题，且只在勾选授权后发送相关记录汇总。模型失败会回退 Mock。当前没有向量库、Embedding、Agent 工具调用或实时联网抓取，不应称为 RAG。模型输出也没有逐句事实核验。

新版求证界面把输入、资料匹配、来源与小行动组织成连续流程。后端返回 `trace`：结果状态、匹配方法、命中词和不能推断的范围。实验模型只收到本次相关摘要及其 `[S1]`、`[S2]` 编号；缺少引用或引用了未提供编号时回退 Mock。格式校验不等于医学事实核验，也不把主题相关说成主张已被证实。十条评测样例覆盖相关资料、无资料、用药和急症路径。腾讯云服务器是计划中的部署环境；模型供应商仍待定，尚缺真实密钥与服务联调。

## 资料来源

知识库为人工编写的简短摘要，每张卡片在界面内提供原始链接：

- [国家卫生健康委员会：中国公民健康素养——基本知识与技能（2024 年版）](https://www.nhc.gov.cn/xcs/c100123/202405/73a4927142f34152abed875634a3c13b.shtml)
- [国家卫生健康委员会：睡眠健康相关信息](https://www.nhc.gov.cn/guihuaxxs/c100133/202503/70d5836afe804a858b899ee951a24a13.shtml)
- [国家卫生健康委员会：老年人失能预防相关信息](https://www.nhc.gov.cn/lljks/c100158/201908/434ad204c8cd4972bb4c9eb42f748f43.shtml)

Demo 不复制长篇原文，不自动更新资料，也不提供个体化医学判断。任何正式使用前须复核每一条摘要与原文的一致性和来源链接的可访问性。

## 安全边界与限制

- 胸痛、呼吸困难、昏迷、自伤等关键词触发紧急就医提示；此规则是演示级关键词匹配，不能保证识别所有紧急情况。
- 药物问题转向医生或药师；资料范围外不生成看似有依据的回答。
- H2 文件持久保存演示数据，并按匿名或账号工作区隔离；邮箱验证码返回本机页面，尚无真实邮件验证、生产级鉴权或完善的数据保留策略。不要在公网上部署此 Demo 或录入真实个人健康信息。账号限制见 `account-security.md`。
- 月度生活方式提示是基于自填数据和画像的资料排序，不是临床阈值判断；活动分钟数没有强度信息，心情 1～5 分也不是心理量表。具体规则与依据见 `health-guidance.md`。
- 模型模式只支持手动配置的兼容接口；提示词和关键词分流不能保证模型回答准确或识别所有风险，需人工复核。
- 当前仅完成本地运行与自动化测试，尚无生产部署。
