# 息刻 Demo 说明

## 定位与体验路径

息刻以健康素养而非疾病诊疗为目标。三类体验画像分别聚焦大学生的作息与压力、职场人士的久坐与休息、年长者的居家安全与日常活动。演示时依次切换画像，完成“首页提问或记录 -> 七日回顾 -> 修正某日记录并观察趋势重算 -> 搜索知识与核对来源 -> 助手追问 -> 将建议加入小行动 -> 勾选或移除”。回顾数据可导出为 JSON。

页面采用横向导航、较大字号和直接可见的提问入口；年长者体验提供字号放大开关，移动端使用底部导航。视觉节奏参考当代 AI 产品站点，但页面结构与内容为本项目原创。所有画像均为虚构示例，无登录及真实用户数据。

## 架构

```text
React 页面 -> Axios /api -> Spring REST Controller
                         -> JDBC Repository -> H2 内存库
                         -> AiService -> MockAiService
                         -> KnowledgeCatalog (人工摘要，最多两条关键词匹配)
                         -> ReviewService (七日描述性统计)
```

前端只处理展示、表单、知识筛选和交互状态。后端处理输入校验、最近七天按日期读写、按画像数据隔离、描述性回顾、资料匹配与 Mock 回答。助手会返回来源和追问话题，并标明是否引用了今日记录；紧急和药物关键词优先分流。`AiService` 是未来模型接入边界。当前没有向量库、Embedding、Agent 工具调用或实时联网抓取，不应称为 RAG。未来若接入真实模型，应由后端持有密钥，并增加引用约束、风险分流、评测与审计。

## 资料来源

知识库为人工编写的简短摘要，每张卡片在界面内提供原始链接：

- [国家卫生健康委员会：中国公民健康素养——基本知识与技能（2024 年版）](https://www.nhc.gov.cn/xcs/c100123/202405/73a4927142f34152abed875634a3c13b.shtml)
- [国家卫生健康委员会：睡眠健康相关信息](https://www.nhc.gov.cn/guihuaxxs/c100133/202503/70d5836afe804a858b899ee951a24a13.shtml)
- [国家卫生健康委员会：老年人失能预防相关信息](https://www.nhc.gov.cn/lljks/c100158/201908/434ad204c8cd4972bb4c9eb42f748f43.shtml)

Demo 不复制长篇原文，不自动更新资料，也不提供个体化医学判断。任何正式使用前须复核每一条摘要与原文的一致性和来源链接的可访问性。

## 安全边界与限制

- 胸痛、呼吸困难、昏迷、自伤等关键词触发紧急就医提示；此规则是演示级关键词匹配，不能保证识别所有紧急情况。
- 药物问题转向医生或药师；资料范围外不生成看似有依据的回答。
- H2 数据随进程退出清空；没有登录、鉴权、多用户隔离或生产隐私方案。不要在公网上部署此 Demo 或录入真实个人健康信息。
- 当前仅完成本地运行与自动化测试，尚无生产部署。
